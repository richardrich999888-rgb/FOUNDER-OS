# Ballast MVP Launch Execution

Ballast should not launch as a generic journaling app, therapy app, or productivity tool.

Launch positioning:

> Ballast is cognitive observability for ambitious minds.

The MVP launch goal is not broad awareness. The goal is to validate whether a small group of founders voluntarily return because Ballast noticed something useful, specific, and trustworthy.

## Launch Stages

1. Internal stabilization: working alpha, core loop, auth, privacy basics.
2. Closed alpha: 10-25 trusted founders/operators/creators.
3. Retention fixes: remove generic AI, reflection fatigue, and invasive tone.
4. App Store readiness: compliance, privacy, deletion, screenshots, store copy.
5. Soft launch: 50-200 users through warm founder channels.
6. Retention analysis: Week 1, Week 4, recurrence, retrieval use, referrals.
7. Iteration loop: prompts, retrieval, synthesis, friction, personalization.

## Brand Guardrails

Use:

- reflection
- awareness
- resilience
- observability
- patterns
- signal

Avoid:

- therapy
- treatment
- diagnosis
- depression detection
- burnout prediction
- mental health claims
- productivity-maxxing
