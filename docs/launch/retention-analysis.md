# Retention Analysis

The first launch metric is not downloads, signups, or impressions.

The metric is voluntary return.

## Core Metrics

- Week 1 retention: user returns 7 days after signup.
- Week 4 retention: user returns 28 days after signup.
- Reflection recurrence: reflections per active user per week.
- Weekly insight opens: percentage of generated insights opened.
- Retrieval usage: percentage of users using search your own mind.
- Voluntary referrals: users who invite or recommend without incentive.

## MVP Success Signal

The strongest signal is:

> This understood something about me.

Track this qualitatively in calls and quantitatively through a post-insight rating.

## Retention Killers

### Generic AI Reflections

Symptoms:

- users say it could apply to anyone
- insights repeat the user's words without adding synthesis
- weekly insight feels like a summary, not a pattern

Fixes:

- improve retrieval precision
- include source-linked memories
- tune prompts around founder context
- reduce confident language when evidence is thin

### Reflection Fatigue

Symptoms:

- users like first session but stop entering reflections
- daily text entry feels heavy
- users say they intended to return but did not

Fixes:

- voice-first capture
- shorter prompts
- one-tap reflection starters
- lower-pressure cadence

### Emotional Discomfort

Symptoms:

- users feel judged
- language feels clinical
- insights feel invasive or overly certain

Fixes:

- softer framing
- non-clinical language
- observability tone
- clear user control over deletion and export
