# Trust Issue Escalation Workflow

Trust issues outrank feature work.

## Severity

P0:

- private reflection content exposed
- deletion does not work
- medical or diagnostic claim shipped
- auth bypass or cross-user data access

P1:

- AI output feels manipulative or invasive
- privacy explanation is unclear
- user cannot understand export/delete controls
- search returns another user's data

P2:

- generic AI output
- confusing onboarding wording
- unclear loading or failure state

## Response Times

- P0: stop alpha expansion immediately, fix before new invites.
- P1: respond within 24 hours, patch in next build.
- P2: batch into weekly iteration.

## Founder Response Template

Use direct language:

> Thank you for flagging this. Ballast is built around trust and private reflection, so we are treating this as a priority. I am checking what happened, what data was affected, and what change prevents it from happening again.

Do not minimize privacy concerns.
