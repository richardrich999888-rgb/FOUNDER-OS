# Android Alpha Tester System

## Onboarding Message

You are invited to the Ballast Android private alpha.

Ballast is cognitive observability for founders and operators. It helps you capture private reflections, search your own history, and review weekly patterns. It is not therapy, medical care, diagnosis, coaching, or crisis support.

This week:

1. Install from the Google Play testing link.
2. Sign in.
3. Add at least three short reflections.
4. Use search your own mind.
5. Generate a weekly insight.
6. Rate whether it noticed something useful.

## Install Instructions

1. Open the Google Play opt-in link.
2. Join the test.
3. Install Ballast from Google Play.
4. Open the app and sign in.

If the link says unavailable, confirm the tester email matches the Google account on the device.

## Feedback Form

Ask:

- Did login work?
- Did reflection save?
- Did search retrieve anything meaningful?
- Did weekly insight feel specific?
- Did anything feel generic?
- Did anything feel invasive?
- Did you voluntarily return?
- Would you miss the app if removed?

## Issue Reporting

Ask testers to include:

- Android device model
- Android version
- app version
- what they tapped before issue
- screenshot if no private reflection text is visible

Never ask testers to paste private reflections into bug reports.

## Retention Tracking

Track:

- day installed
- first reflection date
- first retrieval date
- weekly insight opened
- day 7 return
- would miss answer

## Interview Workflow

After one week, schedule a 20-minute call using `docs/alpha/founder-interview-script.md`.
