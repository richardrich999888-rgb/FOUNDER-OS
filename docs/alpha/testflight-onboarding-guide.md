# TestFlight Onboarding Guide

Goal: get a small group of founders into Ballast without overexplaining or overpromising.

## Before Invites

- Confirm Apple login works.
- Confirm Google login works.
- Confirm `FIELD_ENCRYPTION_KEY` is set in backend production env.
- Confirm `OPENAI_API_KEY` is set.
- Run database migrations through Railway.
- Confirm `POST /api/v1/reflections` works.
- Confirm memory search returns source-linked results.
- Confirm weekly insight generation links to source reflections.
- Confirm export and delete account buttons are visible in settings.

## Invite Copy

Use this:

> I am testing Ballast with a small private alpha. It is cognitive observability for founders: a private way to notice patterns in how you think, decide, recover, and avoid. It is not therapy, coaching, or a productivity tracker. The main question is whether it helps you notice something useful enough to come back.

Do not promise:

- diagnosis
- mental health support
- burnout detection
- emotional optimization
- performance scoring

## Tester Setup

1. Install TestFlight.
2. Accept the Ballast invite.
3. Sign in with Apple or Google.
4. Read the privacy explanation.
5. Add three short reflections across the week.
6. Use search your own mind at least once.
7. Generate a weekly insight.
8. Rate whether the insight noticed something useful.

## Support Path

If a tester reports trust discomfort, generic AI, or account deletion concerns, handle it within 24 hours.
