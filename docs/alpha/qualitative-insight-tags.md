# Qualitative Insight Tagging System

Use this when reviewing alpha feedback and interviews.

## Positive Tags

- `specific-pattern`: user says Ballast noticed something specific.
- `source-trust`: source links increased trust.
- `voluntary-return`: user came back without a reminder.
- `would-miss`: user would miss the product.
- `search-magic`: retrieval surfaced a meaningful old reflection.

## Risk Tags

- `generic-ai`: output could apply to anyone.
- `invasive-tone`: output felt too personal or certain.
- `therapy-drift`: wording felt clinical or therapeutic.
- `reflection-fatigue`: user avoided entering reflections.
- `retrieval-miss`: search failed to find an expected memory.
- `privacy-confusion`: user was unsure where data went.

## Weekly Scoring

Do not turn this into a user-facing score. Internally, count tags weekly to prioritize fixes.
