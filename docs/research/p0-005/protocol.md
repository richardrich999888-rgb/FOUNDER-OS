# Non-confidential research protocol

The research objective is measurable improvement over existing Twin behavior while preserving P0-001–004 authority, memory and evidence boundaries. No result is assumed from an architectural description or a cited paper.

Use separate training, development and held-out tasks. Freeze task inputs and labels before evaluation, retain first failures, disclose same-author synthetic data, and distinguish external structural benchmarks from independently authored semantic tasks. A final test set becomes seen once inspected; later optimization requires a new confirmation set.

Compare against both the existing single-step behavior and a competent conventional baseline. A capability mismatch or zero baseline cannot support a relative percentage claim. Use identical model configurations and comparable budgets when genuine inference is available. Report model-call count, latency, cost where verifiable, safety, missing inputs, negative transfer and failures. A cache or rule filter is not evidence of learned world models or general intelligence.

Missing staging infrastructure, credentials, model files or inference endpoints must produce an explicit BLOCKED result. A synthetic model response is not real inference; local JWKS/SQLite is not hosted Cloudflare authentication or D1 validation. Keep these evidence tiers separate.

Simulated tools must remain visibly simulated. User intent, model proposal, authorization, invocation, receipt and observed outcome are distinct. Missing or contradictory evidence must not become completion. Approval must be rechecked after interruption and context changes. Procedures must remain user controlled and reversible. No external effects, model-weight changes, background surveillance or autonomous delegation are enabled by this research track.

Success criteria are hypotheses: improved completion, fewer unsupported claims, positive transfer, safe recovery and no material privacy/latency/cost regression without justification. Null results are valid research outcomes. Do not optimize for compulsive engagement or emotional dependence. Optimize for the user's stated goal and control.

The private experimental code and invention disclosures are subject to an IP filing/publication decision. This public protocol discloses no new implementation mechanism and grants no deployment or release approval.
