# Privacy Nutrition Labels Draft

This draft must be checked against App Store Connect before submission.

## Likely Collected Data

- Contact Info: email address through Clerk.
- User Content: reflections and optional feedback text.
- Audio Data: only if voice reflection is enabled.
- Identifiers: user ID and device/session identifiers.
- Usage Data: app interactions such as reflection created, search used, insight opened.
- Diagnostics: crash data if Sentry is enabled.

## Not Used For

- third-party advertising
- data broker sale
- cross-app tracking

## Notes

Apple's App Privacy Details page says developers must disclose their own and third-party partner data practices, and free-form text fields can map to Other User Content while voice recordings can map to Audio Data.
