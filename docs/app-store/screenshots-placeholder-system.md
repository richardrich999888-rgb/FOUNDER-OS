# Screenshots Placeholder System

Use placeholders until final UI is ready.

## Required Screens

1. Onboarding: cognitive observability, not therapy.
2. Reflection capture: short private entry.
3. Search your own mind: source-linked retrieval.
4. Weekly insight: source-linked synthesis.
5. Settings: export and delete controls.

## Screenshot Rules

- Do not show real user reflections.
- Do not imply diagnosis or treatment.
- Do not show scores.
- Use calm, concise copy.
- Use mock entries labeled as examples.
